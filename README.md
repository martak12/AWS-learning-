## Courses & Certifications

### 1. Introduction to Amazon EC2
- Platform: AWS Skill Builder
- Topic: Amazon Elastic Compute Cloud (EC2)
- Focus: Understanding cloud computing and virtual servers.

### 2. Introduction to Amazon S3
- Platform: AWS Skill Builder
- Topic: Amazon Simple Storage Service (S3)
- Focus: Cloud storage, buckets, objects, and data management.

### 3. Building Your First Amazon VPC
- Platform: AWS Skill Builder
- Type: Hands-on Lab
- Focus: AWS networking and virtual private clouds.

**Topics covered:**
- Creating an Amazon VPC.
- Creating public and private subnets.
- Configuring Internet Gateways.
- Creating and configuring route tables.
- Configuring security groups.
- Deploying a web server and MySQL RDS instance.
